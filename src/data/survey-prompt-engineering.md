# LLM Prompt Guideline: Engaging & High-Fidelity Survey Design

이 가이드는 설문조사 응답률과 진정성을 높이면서도, 수집된 데이터가 서비스 목적(매칭, 프로필 분석 등)에 부합하도록 LLM을 제어하기 위한 프롬프트 엔지니어링 지침입니다.

---

## 1. 핵심 설계 원칙 (Core Principles)

LLM은 질문을 생성할 때 다음 세 가지 균형을 반드시 유지해야 합니다.

1.  **현실성 (Reality Check)**: "돈과 시간이 무한하다면?" 같은 비현실적 가정보다는, 사용자의 실제 일상과 물리적 행동에 기반한 질문이어야 합니다.
2.  **구체성 (Contextual Specificity)**: "취미가 무엇인가요?" 같은 모호한 질문 대신, 특정 상황(요일, 시간, 장소, 기분)을 설정하여 답변의 허들을 낮춥니다.
3.  **데이터 가치 (Data Integrity)**: 재미있는 질문이라도 결과적으로 사용자의 성향(정적/동적, 외향/내향, 가치관)을 명확히 분류할 수 있는 정보를 담아야 합니다.

---

## 2. 질문 유형별 페르소나 및 전략

| 카테고리 | 기존 질문 (Avoid) | 전략적 질문 (Adopt) | LLM에게 줄 지침 |
| :--- | :--- | :--- | :--- |
| **성격/성향** | 성격이 어떤가요? | 친구들이 말하는 나의 '의외의 모습'은? | 사용자의 '객관적 이미지'와 '자아'를 동시에 파악하게 할 것. |
| **취미/관심사** | 취미가 무엇인가요? | 아무런 약속이 없는 일요일 오후 3시, 당신의 모습은? | '에너지 재충전 방식'과 '구체적 행위'를 연결할 것. |
| **가치관/이상형** | 어떤 사람을 좋아하세요? | 나랑 정말 잘 맞겠다고 확신하게 되는 상대방의 사소한 습관은? | '이상향'이 아닌 '현실적인 매력 포인트'를 끄집어낼 것. |
| **라이프스타일** | 주말에 보통 뭐 하세요? | 요즘 내 유튜브 알고리즘을 가장 많이 차지하는 키워드 3개는? | 현대적인 매체를 통해 실제 관심사를 필터링 없이 노출할 것. |

## 3. LLM 실행 프롬프트 템플릿 (Master Prompt)

LLM에게 질문 생성을 요청할 때 다음 구조를 복사하여 사용하세요.

> **[Role]**: 너는 심리학 기반의 UX 라이터이자 데이터 분석가야.
>
> **[Goal]**: 사용자가 '입력'이 아니라 '자기 표현'을 한다고 느끼게 만드는 설문 문항을 설계해줘.
>
> **[Constraints]**:
> - 문항은 150자 이내로 짧고 간결할 것.
> - 사용자가 답변을 고민하느라 이탈하지 않도록 구체적인 '장면'을 제시할 것.
> - **중요**: 답변 결과가 "사용자의 라이프스타일(동적/정적)" 또는 "사회적 성향(개인/공동체)"을 분석하는 데이터로 쓰일 수 있어야 함.
>
> **[Task]**: 아래의 '딱딱한 질문'들을 위 원칙에 맞춰 '대답하고 싶은 질문'으로 3가지씩 변주해줘.
> 1. [여기에 질문 입력 1]
> 2. [여기에 질문 입력 2]
> ...
>
> **[Output Format]**:
> - 버전 A (위트형): 재치 있고 가벼운 접근
> - 버전 B (감성형): 깊이 있고 차분한 접근
> - 버전 C (돌직구형): 솔직하고 담백한 접근

---

## 4. 나쁜 질문 vs 좋은 질문 예시 (Reviewer's Guide)

- **Bad**: "가장 좋아하는 음식이 뭐예요?" (데이터 가치가 낮고 너무 흔함)
- **Good**: "스트레스 풀고 싶은 금요일 밤, 당신의 배달 앱 최근 주문 내역 1위는?" (실제 행동 패턴과 식성 파악 가능)

- **Bad**: "어떤 스타일의 연애를 원하세요?" (답변이 추상적으로 흐름)
- **Good**: "연인과 함께하는 여행, 당신은 '빡빡한 일정파'인가요, 아니면 '무계획 휴식파'인가요?" (생활 패턴의 직접적 충돌 지점 확인)
